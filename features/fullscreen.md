# Fullscreen Mode

Allow the game to be played in full screen on the current monitor. Focus on wayland for this as most of my systems use wayland.

Center the rendering of the game vertically and horizontally when the game can't be neatly (preserving original design ratios) onto the current resolution.

Implement CLI args to the exe:
  - -f and --full to start in fullscreen
  - -w and --window to start in windowed mode
  - -h or --help to show the CLI args available
